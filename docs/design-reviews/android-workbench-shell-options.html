一个工作台，不再是四个 Tab

三种方案只改变工作台视图的进入方式，任务、双人责任、下一步和审批规则保持不变。点击菜单、头像、视图和新增按钮可查看交互状态。

共同基线冷白背景、深绿主色、珊瑚提示、紧凑任务卡片；“我的”通过头像或菜单进入，不占用底部导航位置。
